## Описание

Лабораторная работа посвящена изучению **Java Collections Framework**:
списки, множества, карты, итераторы, компараторы.

В работе реализованы 5 заданий:

1. **Методы `Collections`** — сортировка, реверс, перемешивание,
   циклический сдвиг, поиск дубликатов, частотный анализ.
2. **Генератор простых чисел** — класс `PrimesGenerator` через `Iterable`/`Iterator`,
   тест `PrimesGeneratorTest` (прямой и обратный порядок).
3. **Множества и сравнение объектов** — `Human`, `Comparable`, компараторы,
   демонстрация `HashSet`, `LinkedHashSet`, `TreeSet`.
4. **Частота слов** — подсчёт вхождений слов через `HashMap`, регистр игнорируется.
5. **Обмен ключей и значений** — без потери значений, значения — `List` ключей.
